# Offgrid asset register

This folder is the canonical reference for every external asset considered or used. Product artwork in the running demo is original CSS geometry, so it remains fast and avoids implying third-party photography is included in a product purchase.

## Brand assets

The OFF/GRID wordmark is an original typographic logo rendered in Syne. Palette: ink `#11120F` (60%), paper/white `#F4F3ED` / `#FFFFFF` (30%), acid lime `#C8FF30` (10%). Supporting campaign colors are violet `#7963EF`, blue `#81CAFF`, and coral `#FF8B6A`.
